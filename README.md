# Enterprise Generative AI Threat Landscape & Risk Assessment
> **Analyst Role & Scope:** I acted as a Cyber Threat Intelligence (CTI) Analyst for this project, aggregating open-source intelligence on Large Language Model vulnerabilities to assess corporate risk vectors against enterprise data perimeters.

## Project Overview
This repository contains a non-coding, research-driven Cyber Threat Intelligence (CTI) assessment report. The objective of this project was to analyze the architectural vulnerabilities introduced when integrating Large Language Models (LLMs) into corporate enterprise environments, mapping threats against modern defense matrices and governance frameworks.

## Core Frameworks Utilized
* **Vulnerability Framework:** OWASP Top 10 for Large Language Model Applications
* **Adversary Behavior Mapping:** MITRE ATLAS (Adversarial Threat Landscape for Artificial-Intelligence Systems)
* **Governance Model:** Google Secure AI Framework (SAIF) & Microsoft Responsible AI Principles

## Key Analysis Domains

### 1. Adversarial Attack Vectors Analyzed
* **LLM01: Prompt Injection (Direct & Indirect):** Investigated scenarios where malicious actors inject hidden instructions into user inputs or third-party web data to bypass model safety barriers, tricking the LLM into executing unauthorized backend administrative tasks.
* **LLM06: Sensitive Data Disclosure:** Evaluated risks associated with LLMs unintentionally outputting proprietary corporate source code, intellectual property, or patient data (CNI boundaries) due to insufficient data data scrubbing.

### 2. Emerging AI-Driven Adversary Tactics
* **Automated Phishing Infrastructure:** Analyzed how nation-state threat actors utilize generative tools to automate the creation of grammatically flawless, highly targeted spear-phishing campaigns at scale.
* **Deepfake Social Engineering:** Researched the tactical deployment of AI voice cloning to bypass organizational dual-factor voice verification protocols in corporate wire-transfer environments.

### 3. Non-Technical Strategic Mitigations (Guardrails)
* **Input/Output Validation Filters:** Proposed standard enterprise deployment architectures for front-end text checking layers (e.g., Llama Guard) to filter malicious prompts before they reach core model interfaces.
* **Data Privilege Segregation:** Formulated access control policies ensuring enterprise chatbots strictly adhere to user role permissions, preventing the model from pulling unauthorized data from backend databases.
